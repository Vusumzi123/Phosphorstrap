Phosphorstrap

Retro-terminal design language — a theme + token layer over Bootstrap 5.3. One page per component; inspect markup and CSS in both themes.

Quick start

Two imports, one attribute — any Bootstrap page becomes a Phosphorstrap page:

<link rel="stylesheet" href="bootstrap.min.css">
<link rel="stylesheet" href="phosphorstrap.css">
<html data-theme="dark">  <!-- or "light" -->

Components

Buttons .btn Forms .form-control Alerts .alert Cards .card Panels .ph-panel Modals .modal Toasts .toast Tables .table Badges .badge Navs & tabs .nav-tabs Calendar .ph-calendar
