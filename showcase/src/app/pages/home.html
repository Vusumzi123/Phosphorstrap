Phosphor

Angular 22 integration showcase — every component and variant, both built-in themes plus a community drop-in, live switching, and a token playground. Doubles as the Phosphor integration test.

Quick start

Two style entries in angular.json, one attribute on <html>:

"styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "node_modules/@vusux/phosphor/dist/phosphor.css"
]

<html data-theme="dark"> — flip it live from the header switcher.

Components

@for (c of components; track c.path) { {{ c.label }} {{ c.markup }} }
