Community themes

A community theme is one CSS file overriding the --ph-* tokens — no component file changes. The shipped example, themes/green-crt.css, is loaded in this app as a real drop-in (after phosphorstrap.css in angular.json) and activated with data-theme="green-crt".

Try it

The whole app — Bootstrap elements included — recolors live. The header switcher does the same from any route.

Wiring (this app)
"styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "node_modules/@vusux/phosphorstrap/dist/phosphorstrap.css",
  "../themes/green-crt.css"          // import AFTER phosphorstrap.css
]
Authoring your own

Copy themes/TEMPLATE.css, rename the theme id, change values. Override any subset — anything you omit inherits from tokens.css / dark.css: 

[data-theme="my-theme"] {{ '{' }}
  --ph-bg: #101418;
  --ph-bg-rgb: 16, 20, 24;
  --ph-surface: #171c22;
  --ph-surface-rgb: 23, 28, 34;
  --ph-text: #d7e0ea;
  --ph-text-rgb: 215, 224, 234;
  --ph-primary: #6cb6ff;
  --ph-primary-rgb: 108, 182, 255;
  /* … */
{{ '}' }}

Rules: --ph-* tokens only, never --bs-* or component selectors; every color ships an --ph-*-rgb companion. Full guide: docs/THEMES.md · live gallery: docs/gallery.html (static playground).
